# Wireframe дашборда — ЛР10

Расположение рассчитано на широкий экран; на узких экранах виджеты располагаются вертикально.

```text
┌────────────────────────────┬─────────────────────────────────────────────────┐
│ ФИЛЬТРЫ                    │ Заголовок + источник данных                       │
│ Период (начало / конец)    ├────────────┬────────────┬────────────┬─────────────┤
│ Регионы                    │ Игроки     │ Сессии     │ Ср. DAU    │ Длительность│
│   ↳ Платформы              ├────────────┴────────────┼────────────┴─────────────┤
│       ↳ Источники трафика  │ Линия DAU по дням       │ Столбцы: регионы/       │
│ Сброс                      │                         │ платформы/источники     │
│                            ├─────────────────────────┼──────────────────────────┤
│                            │ Кольцевая: платформы    │ Тепловая: источник ×     │
│                            │                         │ платформа                │
│                            ├─────────────────────────┼──────────────────────────┤
│                            │ Гистограмма: время      │ Scatter: время × действия│
│                            ├─────────────────────────┴──────────────────────────┤
│                            │ Сегментная таблица + экспорт CSV                   │
└────────────────────────────┴─────────────────────────────────────────────────┘
```

Поток просмотра: слева фильтры, сверху главные KPI, ниже — визуализации от динамики к детальным распределениям. Цветами выделены сравниваемые категории. Подписи осей содержат единицы измерения.
