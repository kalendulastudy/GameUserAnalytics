# Проверка исследовательского дашборда

Этот чек-лист используется для ручной проверки ЛР10 и для документирования результата в ЛР12.

## Команды проверки

```powershell
py -m pip install -r requirements.txt
py scripts/validate_data.py
py -m unittest discover -s tests -v
py -m streamlit run app.py
```

## Проверки интерфейса

- [ ] Без фильтров отображаются 3 343 игрока и 17 399 сессий.
- [ ] Выбор одного региона изменяет KPI и все связанные графики.
- [ ] Выбор региона ограничивает варианты платформ (каскадный фильтр).
- [ ] Выбор платформы ограничивает доступные источники трафика.
- [ ] Кнопка сброса возвращает все фильтры к значениям по умолчанию, включая период.
- [ ] При пустой выборке показывается понятное сообщение без ошибки.
- [ ] Графики читаемы на разрешении 1920×1080.
- [ ] В отчёте указано, что исходные данные синтетические.

## Фиксация результата

Проверяющий заполняет дату, версию проекта (commit SHA), итог команд, обнаруженные проблемы и прикладывает скриншоты из браузера. Пустые пункты чек-листа не считаются пройденными проверками.
