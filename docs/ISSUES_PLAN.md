# План Issues для ЛР12

Это шаблоны задач, их **не следует выдавать за созданные GitHub Issues** до фактической публикации.

| Issue | Метка | Критерий готовности | Артефакт |
|---|---|---|---|
| Проверить и документировать первичный CSV | `data` | нет пропусков, дубликатов session_id, некорректных дат | `scripts/validate_data.py`, описание входных полей |
| Реализовать расчёт KPI | `analysis` | проверены количество уникальных игроков, DAU, длительность | `analysis/metrics.py`, тесты |
| Доработать фильтры и каскадность | `dashboard` | выбор региона ограничивает платформы и источники; KPI обновляются | `app.py`, скриншот |
| Добавить визуализации и drill-down | `dashboard` | минимум 5 разных типов, доступны уровни детализации | `app.py`, скриншот |
| Провести проверку качества | `testing` | запуск без ошибок, тесты зелёные, визуальная проверка 1920×1080 | `tests/`, чек-лист |
| Оформить документацию и итоговый отчёт | `documentation` | README и CONTRIBUTING содержат порядок работы, в отчёте нет выдуманных PR | `README.md`, `CONTRIBUTING.md`, `reports/final_report.md` |

## Канбан-доска GitHub Projects

Статусы: **To Do → In Progress → Review → Done**. Для демонстрации перемести хотя бы две задачи по полному циклу и свяжи один PR с Issue.
