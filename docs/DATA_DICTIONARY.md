# Поля `data/raw/user_sessions.csv`

| Поле | Смысл |
|---|---|
| user_id | Учебный обезличенный ID пользователя |
| registration_date | Дата первого входа/регистрации |
| event_date | Дата рассматриваемой сессии |
| session_start | Время начала сессии |
| session_id | Уникальный ID сессии |
| region | Учебный синтетический регион |
| platform | Учебная синтетическая платформа |
| traffic_source | Синтетический источник привлечения |
| session_count | Единица на строку; каждая строка — одна сессия |
| session_duration_minutes | Синтетическая длительность сессии, мин |
| action_count | Число действий, полученное/преобразованное для учебной модели |
| days_since_registration | Дней между `event_date` и `registration_date` |

Важно: исходный CSV построен в ЛР9 на основе смоделированных событий ЛР8 и дополнен синтетическими характеристиками; это не выгрузка реальных пользователей. Результаты применимы к демонстрации обработки данных, но не к обобщениям о поведении реальных игроков.
